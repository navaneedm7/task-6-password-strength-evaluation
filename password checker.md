###### **3.What Makes a Password Strong?**



A strong password should have:

* Minimum 12–16 characters
* Uppercase letters (A–Z)
* Lowercase letters (a–z)
* Numbers (0–9)
* Symbols (!@#$%^\&\*)
* No dictionary words
* No personal information (name, DOB, phone number)







###### **4.Common Password Attacks**



**1.Brute Force Attack**



Attacker tries all possible combinations until correct password is found.

* Longer passwords make this attack harder.



**2.Dictionary Attack**



Attacker uses a list of common words/passwords.

* &nbsp;Avoid common words like "password", "india123", etc.



**3.Credential Stuffing**



Uses leaked passwords from other sites.

* &nbsp;Never reuse passwords.







###### **5.Best Practices**



* Use passphrases (Example: BlueTiger!Runs@Night2026)
* Enable Two-Factor Authentication (2FA)
* Use a password manager
* Never share passwords
* Change compromised passwords immediately







###### **6.Key Learning**



* Length matters more than complexity alone.
* Adding symbols increases strength.
* Replacing letters with numbers (like a → 4) improves security slightly.
* Randomness is very important.
* Personal information weakens passwords significantly







###### **7.Conclusion**



Password complexity directly affects security.

Long, random passwords with mixed characters are significantly harder to crack using brute force or dictionary attacks.



Using strong password practices reduces the risk of account compromise.
