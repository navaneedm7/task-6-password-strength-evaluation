In this task, multiple passwords with different complexity levels were created and tested using an online password strength checker.
The evaluation showed that simple passwords with common words or short length are weak and easily guessable.
As complexity, length, and character variety (uppercase, lowercase, numbers, symbols) increased, the password strength improved significantly.
The task highlights that longer, random passwords with mixed characters provide better protection against brute force and dictionary attacks.
Overall, password length and unpredictability are the most important factors in creating a strong and secure password.
